## P6YTOK build artifacts

This fork includes a GitHub Actions workflow for building P6YTOK tweak artifacts.

The workflow outputs compiled tweak packages and extracted dylibs. It does not download, store, or distribute TikTok IPAs. IPA test builds should be made separately with a user-provided IPA and signing method.

See [`BUILDING_IPA.md`](BUILDING_IPA.md) for the build path and testing checklist, and [`INTEGRITY_COMPATIBILITY_PLAN.md`](INTEGRITY_COMPATIBILITY_PLAN.md) for the compatibility research plan.
